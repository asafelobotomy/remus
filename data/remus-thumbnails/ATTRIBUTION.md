# Remus Thumbnails

Canonical artwork blobs for the Remus compendium. Generated by `remus-cli --consolidate-thumbnails`
from acquisition sources (primarily [libretro-thumbnails](https://github.com/libretro-thumbnails/libretro-thumbnails)).

## License

(CC BY-NC-SA 4.0). See each upstream repository for full attribution.

Remus transcodes matched assets to tiered WebP (lossless box/title/logo; lossy snaps) and stores them
in a content-addressed blob tree. This directory is a **build artefact** — do not commit `blobs/` or
`manifest.json` to git.
