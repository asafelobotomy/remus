# Security Policy

## Report a Vulnerability

Please report security vulnerabilities privately.

1. Open a private security advisory in this repository.
2. Include affected versions, reproduction steps, and impact.
3. Include any suggested fix or mitigation.

Do not open public issues for unpatched vulnerabilities.

## Response Targets

1. Initial triage within 5 business days.
2. Status update after triage with severity and next steps.
3. Coordinated disclosure after a fix ships.

## Supported Versions

The project currently supports the latest release on the main branch.

## Scope

Security reports are in scope for:

1. Code execution or command injection.
2. Path traversal and archive extraction escapes.
3. SQL injection or metadata poisoning in local databases.
4. Secret leakage in logs, scripts, or workflows.
5. CI/CD supply chain integrity and release artifact integrity.
